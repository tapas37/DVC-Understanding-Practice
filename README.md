# DVC-Understanding-Practice
A beginner-friendly repository for practicing Git and GitHub concepts, including commits, pull, push, and version control.


## About
This repository is created for learning and practicing **Git and GitHub**. It contains small practice files, experiments, and examples while understanding version control.

This is not a production project. It is purely for hands-on practice.



## Purpose
The main goal is to gain practical experience with Git and GitHub by executing commands, making mistakes, fixing them, and understanding how version control works.



**Learning by doing! 🚀**
